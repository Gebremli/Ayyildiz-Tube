# Lizenz- und Autorenhinweise

Ayyıldız Tube ist eine modifizierte Version von **LibreTube**. Die verwendete Version steht in `upstream-version.txt`.

- Ursprungsprojekt: https://github.com/libre-tube/LibreTube
- Urheberrecht am Ursprungscode: die LibreTube-Autorinnen und -Autoren
- Lizenz: GNU General Public License, Version 3 oder neuer (GPL-3.0-or-later), siehe `LICENSE`

Ayyıldız Tube wird von Erol Studio unter derselben Lizenz weitergegeben und steht in keiner Verbindung zu LibreTube, YouTube oder Google.

## Was verändert wurde

Alle Änderungen gegenüber LibreTube stehen nachvollziehbar in `tools/rebrand_libretube.py` und im Ordner `overlay/`:

- Name, Paketkennung, Version, Icon und Standardfarbe
- untere Navigation (Shorts, Merkliste, Einstellungen)
- eigene Update-Funktion über GitHub Releases
- verständliche Fehlermeldungen bei Wiedergabeproblemen

## Quellcode

Zu jeder veröffentlichten APK liegt im GitHub Release ein Archiv `Ayyildiz-Tube-<Version>-source.tar.gz` mit dem vollständigen modifizierten Quellcode. Wer die APK weitergibt, muss diesen Quellcode ebenfalls verfügbar machen.
